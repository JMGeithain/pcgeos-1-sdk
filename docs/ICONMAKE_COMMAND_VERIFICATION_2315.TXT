GEOWORKS/ICONS/PAPR.000

The English manual and the executable's embedded ASCII strings were both
examined. The executable identifies itself as:
  IconMake 1.0 -=- by Marcus Groeber, May 16 1992

The executable's embedded usage text independently confirms:
  ICONMAKE x <geos_file>
      to extract icons to PCX files
  ICONMAKE m[<transp_color>] [<path>]<tokn>[,<num>] {<PCX_file(s)>...}
      to make icons from PCX files
  ICONMAKE w [<path>]<tokn>[,<num>] <ICO_file>
      to make icons from Windows ICO file

The manual gives the concrete extraction naming scheme:
  <token>_CGA.PCX
  <token>_HGC.PCX
  <token>_EGA.PCX

For PAPR.000, the expected output names are therefore:
  PAPR_CGA.PCX
  PAPR_HGC.PCX
  PAPR_EGA.PCX

The documented command to attempt in a DOS environment is:
  ICONMAKE x PAPR.000

This command is supported both by the manual and the executable's embedded
usage string. It is not a guess.

What the source says about the output
-------------------------------------
The manual says the extraction command writes icon definitions to PCX files
using the token-based names above. It does not promise that every source
provider contains all three icon forms. The executable's usage string
confirms the extraction command but does not by itself document the
individual image formats.
